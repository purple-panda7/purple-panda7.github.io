ESTA

Equilibrium Shock Tube Analysis

A desktop application for analysing and designing high-enthalpy facility conditions. ESTA supports reflected shock tube, shock tube and expansion tube calculations, with thermochemical equilibrium properties evaluated using NASA CEA.
